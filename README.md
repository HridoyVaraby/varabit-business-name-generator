# Varabit Business Name Generator

A WordPress plugin that generates creative and relevant business name ideas based on keywords, tone, and industry preferences using Google Gemini 2.0 Flash API.

## Description

The Varabit Business Name Generator helps entrepreneurs and business owners find the perfect name for their business. Simply input keywords related to your business concept, optionally select a tone and industry, and get instant creative name suggestions.

### Features

- Simple, user-friendly interface
- Customizable name generation based on keywords, tone, and industry
- Copy functionality for each name suggestion
- Optional domain availability check
- Mobile-responsive design
- Easily embeddable via shortcode
- Admin settings for API configuration and style customization

## Installation

1. Download the plugin ZIP file
2. Log in to your WordPress admin panel
3. Navigate to Plugins > Add New
4. Click "Upload Plugin" and select the ZIP file
5. Click "Install Now"
6. After installation, click "Activate Plugin"

## Configuration

1. Navigate to Settings > Varabit Name Generator
2. Enter your Google Gemini API key
   - If you don't have an API key, you can get one from [Google AI Studio](https://ai.google.dev/)
3. Select your preferred Gemini model
4. Configure additional options as needed:
   - Enable/disable domain availability check
   - Customize button color and font family
5. Click "Save Settings"

## Usage

### Basic Usage

Add the business name generator to any page or post using the shortcode:

```
[varabit_name_generator]
```

### How It Works

1. Enter keywords related to your business concept
2. Optionally select a tone (Fun, Professional, Trendy, Luxurious)
3. Optionally select an industry/niche
4. Click "Generate Names"
5. View the generated business name suggestions
6. Use the "Copy" button to copy individual names
7. Use "Copy All" to copy all names at once
8. Click "Generate More" to get additional suggestions

## Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
- Google Gemini API key
